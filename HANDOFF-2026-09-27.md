## 6. Decisions logged — improvements we chose NOT to adopt (and why)

Standing reject list — do not re-litigate without new evidence:

1. **Atomic MoE decode accumulation (`B12X_GLM53_ATOMIC_*`)** — non-deterministic
   run-to-run. Determinism posture: our lane is kernel-deterministic, NOT bit-reproducible
   (greedy text moves with batching; knapcio's scheduler docstring says so). Never publish
   "deterministic" for this lane.
2. **RoCEnante collectives on our ring** — built and measured on a switched two-rail
   fabric; ours is switchless. Transport qualification required first; reject as a mount.
3. **Custom NCCL builds (RiNGSiDE 0001/0002, knapcio host build)** — our switchless
   v0.0.1 (`~/nccl-switchless-v0.0.1`, sha-pinned, checksummed at every boot) is proven;
   their subnet pins don't match our 10.10.0.0/22 addressing.
4. **Fork-only vLLM flags** (`--per-request-spec-decode-metrics detailed`,
   `--cudagraph-metrics`, `--kv-cache-metrics`, profiler env) — v11 lacks the symbols;
   same failure class as the aborted E27c port (5 symbol drifts, 5 boots, abort).
5. **`top_p 0.95` override / `clear_thinking` template / GLP-44 steering** — wrong
   checkpoint default, foreign template, not our use case.
6. **TP2-lane knobs into TP4** (e.g. `DFLASH_TOKENS=3`).
7. **LibertAIDAI NVFP4 weights** — quantizes attention → intermittent corrupted token IDs
   (vllm#54150; measured 4/9/8 corrupted vs 0/0/0 for nvidia/RedHat/LIL on this stack).
8. **RedHatAI NVFP4 as a weights swap** — W4A4, throughput loss vs LIL in the field table;
   only relevant as part of a Phase 4(a) wholesale move.
9. **RadixArk (absmax-only W4A4), ormandj (SGLang/SM120 target)** — wrong scaling or wrong
   engine.
10. **`lossless8` weight conversion** — offline converter + full numeric revalidation;
    only worth it on the Marlin/RoCEnante path Phase 4 may moot.
11. **mem-util 0.87** — UMA OOM history (6 failed boots pre-Phase-1); grow KV via the pin.
12. **Prefix-repair mount (`QUAD_PREFIX_REPAIR=on`)** — TEMPORARILY rejected, not
    permanent: hangs all four ranks at init (mamba flips to `align`); retry after 9e.
13. **E27d per-step prefill cap** — upstream (jnardiello) discarded it themselves
    (2026-09-27 pull); prior art against a future fair-prefill attempt here.
14. **RiNGSiDE image wholesale as a reflex** — gated behind Phase 3 data (Phase 4 decision).
15. **`--compilation-config mode:3` / seqs 16** — only after confirming mode 3 exists in
    v11; graphs must cover the admitted sizes or it costs more than it gains.

## 7. Notes to self — what was learned, steps to take

**Learned this session (each is a mechanism, not an anecdote):**
1. **instanttensor pip must be `--no-deps`.** Plain pip pulls nvidia-nccl 2.29.7 and
   breaks the preloaded switchless lib (deep_ep asserts the exact SO). The image build
   bakes it; the container probes it fail-closed at every boot.
2. **`docker run <image> python3 -c …` silently becomes a vllm-serve parse error** in
   this image (entrypoint). Always `--entrypoint python3`. Same class of trap bit both
   the stage script and the check script — the check needed to be a piped `bash -s` file,
   not an inline quoted command (nested-quote mangling).
3. **TileLang cache does not live under `~/.cache`.** `TILELANG_CACHE_DIR` must be set
   explicitly or every boot recompiles `mhc_pre_big_fuse_with_norm_tilelang` 12–14×,
   ~5 s each, mid-inference. Fixed via `/cache/tilelang`.
4. **KV pool scales slightly with `max_model_len`** (3,154,184 @262K → 3,459,187 @384K at
   a fixed 24 GiB pin). Unexplained — block rounding + reservation shape is the guess.
   Re-measure if the pin or dtype ever changes.
5. **A long-context probe must self-calibrate from the server's token count.** Filler text
   tokenised 5.27 chars/token, not 4; the first "270K" attempt was 205K and the test would
   have been vacuous. `longctx_probe.py` now resends with the measured ratio and asserts
   `prompt_tokens > 262144`.
6. **Background clients own :8888.** Hindsight extraction + devops crons hit it
   continuously; any throughput number taken without an idle-window guard measures their
   traffic too. `bench-idle.sh` exists for this; use it or don't publish the number.
7. **"Attention-clean" is a property of the target list, not the ignore list.** LIL has
   `ignore: []` yet is clean because only routed experts are targeted. Read targets, not
   ignore, when triaging a ModelOpt checkpoint.
8. **2ca4 disk is the recurring binding constraint.** 121G node; we reclaimed to ~164G
   (dead images, 46G stale /root/.cache/huggingface) and it is back to ~29G after staging.
   dc90 is at 14G. Before ANY new staging: check `df` on all four ranks first.
9. **Boot facts are receipts; throughput is a hypothesis until idle-guarded.** All the
   durable wins this session (load 9 min → 67 s, boot 13 → 4 min, KV ×2 via pin, prefix
   caching 8.27×) were log facts, not timing runs.
